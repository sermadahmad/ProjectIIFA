## Getting Started

1. Clone the repository:
   ```powershell
   git clone https://github.com/sermadahmad/ProjectIIFA.git
   ```
2. Install dependencies:
   ```powershell
   npm install
   ```
3. Run the app:
   ```powershell
   npx react-native run-android
   # or
   npx react-native run-ios
   ```

## Project Structure
- `src/` - Source code and assets
- `android/` - Android project files
- `ios/` - iOS project files

## Design
All screen designs are created in Figma and exported as images to `src/assets/screenshots`.
