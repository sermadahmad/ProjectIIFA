# ProjectIIFA

## Overview
ProjectIIFA is a React Native mobile application featuring a modern onboarding flow, authentication screens, and intuitive navigation using both drawer and bottom tabs.

## Features
- **Splash Screen**: Displays a branded splash screen on app launch.
- **Onboarding**: Guides new users through the app's key features with engaging visuals.
- **Authentication**: Includes Login and Signup screens for secure user access.
- **Drawer Navigation**: Provides easy access to main sections via a side drawer menu.
- **Bottom Tabs**: Allows quick switching between core screens using bottom tab navigation.

## Screens
- SplashScreen
- OnBoardingScreen
- AuthScreen (Login/Signup)
- HomeScreen
- ProfileScreen
- SettingsScreen
- AnalyticsScreen
- HistoryScreen
- CreatePostScreen
- LogoutScreen

## Getting Started
1. Clone the repository:
   ```sh
   git clone https://github.com/sermadahmad/ProjectIIFA.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Run the app:
   ```sh
   npx react-native run-android
   # or
   npx react-native run-ios
   ```

## Folder Structure
- `src/` - Main source code
- `android/` - Android project files
- `ios/` - iOS project files
- `assets/` - Images, videos, and screen recording
